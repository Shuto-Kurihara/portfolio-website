# SHUTO KURIHARA — Portfolio

白を基調に、大きなセリフ体の名前と写真を配置した、日本語・英語切替対応のポートフォリオです。各言語にトップ、スキル、作品の3ページを用意しています。HTML / CSS / JavaScriptだけで動作します。

## ファイル

- `index.html` — プロフィールと経歴
- `about-me.html` — スキルと使用ツール
- `works.html` — 制作物と公開リンク
- `index-en.html`, `about-me-en.html`, `works-en.html` — 各ページの英語版
- `style.css`, `script.js` — 共通デザインとモバイルメニュー
- `hero-photo.webp` — ヒーロー画像
- `robots.txt`, `sitemap.xml` — 検索エンジン向け

ヘッダーの言語リンクは、同じ内容のもう一方の言語ページへ移動します。日本語と英語の表示をページ単位で切り替える構成です。

- 作品ページとFigmaプロトタイプの公開範囲

## GitHub Pagesで無料公開する

1. 公開リポジトリ `Shuto-Kurihara/portfolio-website` に、このフォルダー内のサイトファイルを最上位へ追加します。
2. 変更をコミットします。既存の `cafe` と `html-test` フォルダーはそのまま残します。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** で **Deploy from a branch** を選び、`main` ブランチの `/ (root)` を指定して保存します。
5. Pagesが表示するURLを開き、スマートフォンからも確認します。

## 検索エンジン向け設定

ページごとのタイトルと説明文、OG情報、canonical、日英の `hreflang`、Person構造化データ、`robots.txt`、6ページ分の `sitemap.xml` を用意しています。GitHub Pages公開後、Google Search Consoleにサイトを登録してサイトマップを送信し、トップページのインデックス登録をリクエストしてください。検索結果への掲載・順位・反映時期は検索エンジンが決めるため、上位表示は保証されません。公開可能な実績の説明や制作過程の記事を追加し、情報を更新していくことが検索者に役立つサイトづくりにつながります。
